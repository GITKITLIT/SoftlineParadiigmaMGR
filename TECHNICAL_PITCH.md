# Техническая часть защиты

Впишите проверенный SHA и URL стенда перед показом. Техническое объяснение занимает около 2 минут из пяти минут выступления. Оставьте время на бизнес-проблему и живой проход по заранее подготовленному сценарию.

| 1. Архитектура | Браузер через Nginx и HTTPS обращается к Python Backend. AI Core получает исходные данные и запускает локальную Qwen через llama.cpp. Наблюдения и решения хранятся в SQLite v6. | Схема из [README](README.md), граница защищённого контура |
| 2. От сигнала до расследования | Монитор сравнивает ряды, запускает расследование по порогу. Модель выбирает инструменты из списка. Python считает показатели, привязывает их к окну и источнику. Гипотеза сопровождается проверкой. | Сигнал, основной и контрольный ряды, журнал инструментов и ссылка из гипотезы |
| 3. Сверка источников | Метрика, импорт продаж и воронки, релизы и конкурентный поиск имеют отдельные статусы. Search сохраняет происхождение и дату. Цены сравниваются при совпадении условий. | Карточка доказательства, статус неподключённого источника, история PIM |

| 5. Эксплуатация | Приватная история по владельцам, loopback для модели и Backend, независимый vault, синтетический контур жюри. CI проверил резервирование и откат SQLite. | Граница ролей приложения, модели, backup; стоимость токенов, инфраструктуры и Search отдельными строками |

Для описания в кабинете используйте такой текст после сверки финального SHA и объёма разработки.

> ParadiigmaMGR помогает менеджеру интернет-магазина проверить падение продуктовых показателей и довести расследование до согласованной задачи. Загрузите данные или откройте подключённый источник, сравните основной ряд с контрольным и проверьте доказательства. Агент выбирает инструменты в рамках доступных источников, ссылки на расчёты и наблюдения сохраняются в продуктовой памяти. Менеджер подтверждает изменения в бэклоге, экспортирует Redmine JSON и задаёт план замера эффекта. В поставке Python Backend, веб-интерфейс, SQLite v6, настройки развёртывания и демонстрационные данные. Модель Qwen3-4B Q4_K_M запускается через llama.cpp отдельно.
>
> Подготовлен путь к пилоту с приватным контуром и резервным копированием. Прямая запись в Redmine вне текущей поставки. Создание презентаций и видеообзоров продуктов не заявлено как реализованная функция. Показанный эффект на синтетических данных иллюстрирует способ расчёта.
