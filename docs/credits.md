# Авторы, происхождение и лицензии

PARADИИGMA разработана командой PARADИИGMA для конкурса «ИИкузница» на базе существовавшего командного прототипа. Авторство отдельных вкладов сохранено в Git. [История участников](https://github.com/GITKITLIT/SoftlineParadiigmaMGR/commits/92a12b42e9b78a3103833cff24426513880208b2/)

В разработке команда использовала Codex для анализа вариантов, подготовки синтетических данных и документации, реализации и проверок AI Core. Продукт опционально использует Qwen3-4B через llama.cpp. Веса, бинарники и ключи к внешним сервисам поставляются отдельно.
