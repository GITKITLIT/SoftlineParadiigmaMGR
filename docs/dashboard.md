# Dashboard

Откройте приложение по [инструкции запуска](../README.md#быстрый-запуск). Для локальной демонстрации используйте встроенные синтетические данные и отдельный каталог SQLite.

| Раздел | Действие |
| --- | --- |
| Обзор и Метрики | Сравнить заказы с контрольным рядом, перейти к графику и настроить окна. |
| ИИ-агент и Журнал | Запустить расследование и вернуться к нему после перехода в другой раздел. |
| Чат с Qwen | Создать или выбрать диалог. Введённый текст сохраняется при переходах внутри страницы, отправленные ответы доступны истории. |
| Бэклог и Оценка эффекта | Открыть согласованную задачу, экспортировать Redmine JSON и проверить расчёт на синтетических неделях. |
| Исследования, Конкуренты и База знаний | Найти сохранённые материалы и сравнить исторические периоды. |

Сохранённый отчёт открывается по фрагменту `#report=<id>`. Ссылка на доказательство добавляет `&ref=evidence-…`. Передавайте такие ссылки пользователям с доступом к тому же экземпляру. На мобильном устройстве выбор раздела закрывает меню. Клавиша Escape также закрывает меню.

Порядок автоматической и ручной проверки описан в [тестировании](testing.md). При развёртывании пересоберите CSP для [активного JavaScript](deployment.md#csp-после-обновления-dashboard).
