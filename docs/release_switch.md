# Переключение и откат

Зафиксируйте SHA обоих Backend, конфигурации служб и фактический CSP. Снимите обе SQLite, согласованные документы, конфигурации и сертификаты. Ограничьте доступ к операторской копии. Проверьте контрольные суммы и восстановление в отдельную директорию. Запретите новые записи на время переключения.

Установите зафиксированный SHA через `scripts/deploy/update.sh`. Backend использует прежнюю SQLite v6. Переключите рабочий каталог и интерпретатор отдельной replay-службы. Сохраните её собственную базу и настройки. Активируйте профиль Qwen только на Backend с туннелем. Для каждого vhost рассчитайте CSP по фактически встраиваемому JavaScript и выполните `nginx -t` перед reload.

При откате сохраните текущие базы. Верните предыдущий выпуск, конфигурации окружения, Nginx и исходный replay unit. Перезапустите службы и проверьте HTTPS, обе базы и health. Восстанавливайте базы из снимка при несовместимой схеме или повреждении после сверки новых записей. [Штатный откат](combined_release_deployment.md) · [Резервирование](disaster_recovery.md)
