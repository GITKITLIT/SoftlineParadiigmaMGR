# UX-аудит для жюри

Проверена интеграционная база `5e956ca08f67cd0d4501596d85c14493239b8ffa` 27 ноября 2026 года. Windows, Edge в чистом временном профиле, локальный сервер на loopback, отдельное синтетическое состояние. Модель, Метрика, платный Search и внешний SMTP не подключались. Журналы браузерных smoke проверяли необработанные JavaScript-ошибки; тесты завершились без них.

| Шаг | Результат и основание |
| --- | --- |
| Первый экран и переходы | `scripts/qa_browser.py` прошёл: карточка −30%, ссылка на динамику, числа периода и открытие связанной задачи |
| Мониторинг и расследование | `scripts/pim_acceptance.py` прошёл: автоматический сигнал, отчёт, доказательства, гипотеза, согласование |
| Ссылки и источники | Smoke прошёл локальный импорт и поиск отрывка, показ групп доказательств и отсутствие внешнего подключения. Три целевых Search-теста прошли, включая сохранение происхождения при импорте |
| Модель и чат | Проверен явный резервный результат. В `scripts/qwen/browser_smoke.py` использован установленный Edge. Проверены отправка, уточнение, ссылки на предыдущее сообщение, история по владельцам, сохранённый план эффекта и мобильный режим |
| Черновик и бэклог | Оба сценария прошли. Проверены отмена, редактирование, повтор сохранения, явное согласование и повторное чтение записи |
| Redmine | После согласования `POST /api/tasks/redmine-export` вернул непустой JSON на локальном сервере. Кнопка в веб-интерфейсе отсутствует |
| Эффект и PIM | Проверены ожидание новых недель, симуляция, историческое сравнение, снимок SQLite, восстановление и новая запись |
| Живые зависимости | Предыдущая приёмка подтверждает локальную Qwen на Windows CPU и TLS SMTP с тестовым реле. Handoff Search подтверждает HTTP 200 и кеш. Загрузка модели на новом VPS, HTTPS-вход, внешний SMTP и сценарий живой недоступности API на стенде ждут проверки |

| Приоритет | Наблюдение | Действие |
| --- | --- | --- |
| P0 выпуска | Доступность внешнего стенда и вход под ролью жюри не подтверждены | Максим передаёт URL и проверяет пользовательский сеанс с чистого браузера. После этого сверить нюансы гида, пиковую нагрузку и сохранение между сеансами |
| P1 | Для Redmine JSON нужен API. Из карточки задачи жюри не может скачать его напрямую | В [гиде](JURY_GUIDE.md) приведён рабочий маршрут; оператор может подготовить экспорт. Добавление кнопки выходит за объём этой подготовки |
| P1 | Подпись «Скачать калькулятор стоимости» ведёт на `cost.xlsx`; выдача требует заранее сгенерированного файла. Генератор проекта использует условные данные без замера | Перед выпуском проверить наличие и назначение файла по ссылке, официальный утверждённый Excel отдельно приложить в заявку |
| P1 | В локальном анонимном запуске чат работает, если включён флаг `PM_QWEN_CHAT_ENABLED`. При отключённой модели в части экрана остаётся название Qwen | Гид и Quick Start включают чат и описывают резервную ветку |
| P2 | Отдельно видны демонстрационный браузерный и серверный бэклоги. Сходные названия могут запутать при показе | Для согласованной записи и экспорта вести жюри в «Журнал и задачи» |

Изменений продукта по итогам проверки не понадобилось. В операторской инструкции исправлено создание каталога истории Search, без которого проверка останавливалась на пустом контуре.
