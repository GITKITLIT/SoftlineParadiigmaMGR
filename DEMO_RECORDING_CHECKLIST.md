# Чек-лист записи PARADИИGMA

Сценарий рассчитан на **02:50 одним дублем**. Рекордер захватывает окно с готовым синтетическим отчётом, отдельную вкладку с протоколом Search и подготовленные визуальные материалы. План работы на принятой базе `5e956ca` опирается на синтетическую репетицию кода `c25dea9`. [Сценарий записи](DEMO_VIDEO_SCRIPT.md) · [Исходный сценарий](https://github.com/GITKITLIT/SoftlineParadiigmaMGR/blob/cd00670bef2d4bdba4f07a4e0a88afacdaa553e7/DEMO_SCENARIO.md)

## До записи

1. Капитан сверяет допустимые данные задачи с условиями подачи. Для публичного ролика готовьте изолированный синтетический профиль. Рабочая SQLite, корпоративные документы, интервью, эталоны, адреса почты, секреты, вкладки администратора и терминал не попадают в кадр. Уведомления ОС выключены. [Положение, п. 4.5](https://xn--80ancabkw0c4a.xn--p1ai/regulations/v1.html)
2. Используйте существующий лаунчер из снапшота бизнес-демо с тем же именем прогона и профилем. Подготовленное состояние включает синтетическую базу, браузерный профиль и связанные локальные доказательства. Работайте с него. Если состояния на машине записи нет, оператор перед записью готовит его штатным `rehearse` с новым именем и переносит это имя в команды ниже. Понадобятся локальная модель, первый тик через 60 с и время расследования. [Инструкция лаунчера](https://github.com/GITKITLIT/SoftlineParadiigmaMGR/blob/cd00670bef2d4bdba4f07a4e0a88afacdaa553e7/demo/README.md)
3. Запустите утверждённую локальную Qwen по README. Из корня копии бизнес-демо откройте один сеанс для записи. Лаунчер поднимет браузер с тем же профилем и откроет якорь сохранённого отчёта. Единственная планируемая новая модельная операция во время записи — исторический вопрос. В replay фоновый монитор и тестовое SMTP-реле выключены. Для просмотра сохранённого без модели доступен обычный replay.

```powershell
python -X utf8 demo/rehearse.py replay dress --live-replay
# Только просмотр сохранённого без модели, вместо команды выше
python -X utf8 demo/rehearse.py replay dress
```

4. Сохраните в закладках якорь отчёта и откройте в том же синтетическом профиле дополнительные вкладки для задачи, сравнения PIM и протокола Search. Вкладку PIM выставьте на ряд и даты сценария, выполните только обычное «Сравнить периоды» для запасного показа, форму исторического вопроса оставьте без отправки. Не открывайте параллельно второй экземпляр лаунчера с тем же профилем.
5. Подготовьте `data/effect-demo.json` для диалога выбора файла. Разместите безопасную, читаемую копию существующего `redmine.json` в отдельной вкладке или окне без видимого абсолютного пути. Имена и идентификатор должны относиться к той же согласованной синтетической задаче. Откройте отчёт Search на таблице фактического результата. [Сохранённый результат Search](https://github.com/GITKITLIT/SoftlineParadiigmaMGR/blob/574b3917ad57b8370f408552ffab6ea69462f831/SEARCH_LIVE_ACCEPTANCE.md#фактический-результат)
6. По передаче владельца стенда выберите варианты двух коротких эпизодов. Для HTTPS нужны внешний вход под ролью жюри и проверенная версия. Для внешней почты нужны подтверждение получения тестовым адресатом и проверенная ссылка на связанный отчёт. Подготовьте окна заранее и скройте данные входа и адресата. Если подтверждения нет, оставьте готовыми локальные доказательства из сценария. Используйте ту же цепочку «сигнал → отчёт» для каждого показанного письма и явно называйте его контур. [Операторский порядок](https://github.com/GITKITLIT/SoftlineParadiigmaMGR/blob/5e956ca08f67cd0d4501596d85c14493239b8ffa/docs/final_release_operator.md)

## Перед передачей дубля

- [ ] Длительность 02:45–02:55. Съёмка одним фрагментом, в кадре различимы режим и происхождение данных.
- [ ] Видны отчёт и проверяемая гипотеза, согласованный тег, подготовленный JSON и план оценки эффекта.
- [ ] На экране симуляции читается подпись, на экране Search — 200, 1,58 с, три наблюдения и 7,4 мс. Живой исторический запрос назван живым, только если в дубле есть свежий ответ модели и шаг инструмента.
- [ ] Слова про HTTPS и email соответствуют показанному доказательству. «Принято SMTP» относится к приёму реле.
- [ ] Ни в кадре, ни в озвучке нет секретов или закрытых данных. Капитану передана ссылка, открывающаяся с нужной ролью, и указана принятая ревизия.
