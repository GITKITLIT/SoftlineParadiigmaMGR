Кандидат для обсуждения с владельцем AI Core. В проверенном комплекте эти функции выполняет Python.

Для черновика используй данные расследования, назови проверяемую гипотезу, альтернативу и критерий. Проверь совпадения в бэклоге. При совпадении предложи пересмотр существующей задачи. Оставь цель пустой, если её основание не согласовано. Сохраняет только пользователь.
Для оценки используй только расчёт сервера по полным неделям. Укажи базу, цель, контроль, побочные показатели и качество наблюдения. Симуляция показывает работу метода. Фактический вывод требует наблюдений после релиза. Если окно неполное, сообщи, чего ждать.
