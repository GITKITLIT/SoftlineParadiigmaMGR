Для точной реплики «Что проверить первым?» подготовлен прежний отчёт синтетического мониторинга в режиме без модели. В калькулятор вошёл только фактический новый ход на Mac с `llama.cpp b12800`, одним слотом, 8192 токенами, 4/4 потоками и кешем 512 МиБ. Чтение уже сохранённого плана выполнено из того же отчёта и подтверждено без модельных вызовов. R‑09 взят из существующей трассировки однослотового прогона Mac на `c25dea9`; отчёт прошёл 11 сверок, повторный запуск для калькулятора не понадобился. Эти строки измерены в отдельных сессиях и подходят для оценки отдельных шагов. По ним нельзя определить полное время связной демонстрации или задержку на 1Gb.ru.

Новый проход выполнен 27 ноября 2026 года на Mac M5 Metal, утверждённой Qwen3‑4B Q4_K_M и принятой ревизии `5e956ca08f67cd0d4501596d85c14493239b8ffa`. `llama.cpp` build 12774, кеш 512 МиБ, два слота по 8192, 4/8 потоков, non-thinking и принятый промпт. Это один проход по сценарию для разбивки токенов. Первый запрос выполнен после готовности модели, остальные — в том же процессе. Табличное время измерено от запуска Core до результата, без сети пользователя и HTTP-прокси приложения. Linux-расценки и SLA требуют своего прогона.

## Как читать CSV

- `legacy_aggregate` — прежние измерения `mac-m5-live.json` и `mac-m5-cache512.json`. Они сохраняют исходные суммы и время. Пустые поля означают отсутствие сведений, в том числе исторического числа вызовов и разбивки по стадиям. Новая разбивка относится к своему прогону. `model_tools` в прежних отчётах — действия модели. Завершающий вызов планировщика и повтор синтеза могут не добавлять действия.
- `instrumented_request` — одна расчётная строка на сценарий с расходом по стадиям. `instrumented_http_call` — детализация той же строки. В калькуляторе импортировать один уровень. Для нового прохода число вызовов подсчитано по фактическим POST. Планирование учитывает `investigation_action` и вспомогательную схему `next_step` при наличии. Синтез учитывает `investigation`, включая повтор после проверки. В `simple_chat` два завершившихся HTTP-ответа синтеза вошли в бюджет, хотя итоговый отчёт один. Нулевой синтез у истории и конкурентов подтверждён трассировкой.
- `legacy_pair_wall` — полное время пары. Строки `concurrent_client` — два отдельных запроса одной пары. Сумма длительностей отдельных клиентов не равна времени работы пары. `transport_probe` — отдельный прямой HTTP SSE-запрос, подходит для TTFT и скорости генерации. В нагрузку продакта транспортную пробу не включать.
- Суммы токенов всех 58 вызовов в детализации сверены с `usage` отчётов Core. `pm/investigation.py` складывает usage планировщика и синтеза. Токены сервера включают логический вход при переиспользовании части префикса. В Linux при тайм-ауте учитывать сам вызов, а неизвестные счётчики помечать пустыми.
- `follow_up` считает только второе сообщение. Предыдущий ход создаётся отдельно при подготовке фикстуры. `release_brief` включает создание расследования для первоначальной выжимки. Повторное открытие сохранённой выжимки читает SQLite и не вызывает Qwen. `monitor` — одно сработавшее расследование. Период опроса и число срабатываний задаются отдельно.

## Официальные входы

`scripts/cost.py --benchmark FILE --output FILE` принимает один JSON. Сопоставляйте числа из одной `instrumented_request` строки. Здесь `seconds` — замер Core, который служит оценкой времени запроса. Измеренное время HTTP-профиля помещайте туда после прогона такого профиля. Поле даты относится к завершению измерения.

```json
{
  "model": "Qwen3-4B Q4_K_M",
  "seconds": 12.677,
  "calls": 7,
  "usage": {"prompt_tokens": 8052, "completion_tokens": 271, "total_tokens": 8323},
  "measured_utc": "2026-11-27T17:01:25Z"
}
```

Для недельной модели нагрузки `scripts/qwen/cost.py` и комбинированного `scripts/deploy/estimate_cost.py --qwen-benchmark …` передавайте полный `llm_lab/benchmarks/mac-m5-live.json`. Поднабор `mac-m5-cache512.json` не покрывает все сценарии недельного калькулятора. Подтверждённая оценка старого Mac-профиля — **0,1304**, **0,4823** и **3,1210** эквивалентных часа в неделю для 1, 5 и 35 продактов соответственно. Приняты текущие частоты калькулятора и 7 расследований мониторинга на весь стенд. Для утверждённой схемы 1Gb.ru относится к строке `dedicated_model_vm`, Yandex Cloud — к `application_vm`. Тарифы берутся из фактических коммерческих предложений. Время круглосуточной аренды одного VPS составляет 168 ч в неделю. Оценку активных вычислений используйте для сравнения. Постоянный модельный сервер уже учтён в инфраструктурной строке. Дополнительные расходы на поиск, хранилище, трафик и SMTP вносятся отдельно по фактическим тарифам.

## Цена и выбор строк для Excel

Модель self-hosted. В колонке `token_price_rub` проставлен 0 ₽ за токен. Стоимость аренды, трафика и хранения учитывается отдельно. Для простого чата берите строки `simple_chat`, для полного синтетического расследования — `drop`. Для детализации выбирайте строки модельных вызовов одной сессии и сверяйте сумму с соответствующей строкой сценария. Суммировать оба уровня нельзя. Пустое значение фазы или токенов означает отсутствие измерения, включая отдельные HTTP-тайм-ауты и агрегаты прежних прогонов.
